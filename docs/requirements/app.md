# 要件定義テンプレート

## 1. 概要

- **プロジェクト名称:**
  - 食費管理
- **目的:**
  - １食にいくら使ったのかを詳しく管理したい
- **概要:**
  - 買い物から在庫登録、在庫から料理、料理から在庫、在庫から消費への流れを管理する機能。

## 2. 背景・目的

- **現状の課題:**
  - 食パン6枚入りを一枚食べると100/6を計算して入力している、料理を作るとそれがもっと複雑になる。
- **解決策:**
  - 入力したらすぐ家計簿に入るのではなく、買い物→在庫、在庫→料理、料理→在庫、在庫→消費という流れで管理したい。
- **期待される効果:**
  - 1食あたりの正確な食費原価の把握。
  - カレンダーによる視覚的な支出管理。

## 3. ユーザー要件

- **ターゲットユーザー:**
  - 節約をしたい人
- **主要なユースケース:**
  - 購入した食品（食材）を在庫として登録する。
  - 在庫食材を組み合わせて料理を作成し、原価を算出する。
  - 日々の消費内容をカレンダーで確認する。

## 4. 機能要件

- [ ] **カレンダー表示機能:**
  - 詳細: 今日いくら使ったか、日ごとの合計金額をカレンダー上で一目で確認できる画面。
- [ ] **在庫・消費管理機能:**
  - 詳細: 買い物から在庫登録、在庫から料理、料理から在庫、在庫から消費への流れを管理する機能。
